🔄 바이브코딩 3단계 사이클

코딩 문법 암기 대신, 자연어로 요청하고 즉시 확인하며 대화로 고쳐나가는 순환 루프입니다.

1. 요구사항 정의 (Prompting)

화면 레이아웃, 버튼 동작, 데이터 규칙을 일상의 자연어로 구체적으로 지시합니다.

2. 즉각 실행 & 검증 (Preview)

Google AI Studio 등의 미리보기 창에서 직접 버튼을 누르고 데이터를 넣어보며 확인합니다.

3. 대화형 디버깅 (Refining)

"버튼을 눌렀을 때 반응이 없어, 콘솔 에러 없이 고쳐줘"와 같이 대화로 품질을 높입니다.
